# LUMORA - Luxury Haute Parfumerie (React App)

A modern, high-end React e-commerce web application for LUMORA luxury fragrances. Built with **React 18**, **Vite**, **React Router v6**, **Lucide Icons**, and custom luxury CSS styling.

## Features

- **Dynamic Catalog**: Filter by fragrance family, price range, and search query.
- **Product Detail**: High-resolution gallery, olfactory pyramid (top, heart, and base notes), longevity & sillage guides.
- **Interactive Cart & Drawer**: Add to cart, quantity adjustments, luxury gift packaging toggles.
- **Wishlist**: Real-time persistent wishlist across sessions.
- **Checkout Flow**: Complete checkout flow with coupon code support, shipping selector, and order summary.
- **Customer Authentication**: Sign In / Sign Up screens with interactive validation and persistent session storage.
- **User Profile**: Edit profile details, order history overview, and preferences.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Navigate to the lumora-react directory
cd lumora-react

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Visit `http://localhost:5173` to explore the luxury storefront.

### Building for Production

```bash
npm run build
```

The production assets will be output to the `dist/` directory. You can preview the build with:

```bash
npm run preview
```
